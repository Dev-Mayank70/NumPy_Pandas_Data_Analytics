# NumPy & Pandas Data Analytics Assignment

## Overview

This project demonstrates practical applications of NumPy and Pandas for Data Analytics.

## Technologies Used

- Python
- NumPy
- Pandas
- Jupyter Notebook / VS Code
- CSV datasets

## Tasks Covered

1. NumPy Introduction & Arrays
2. NumPy Indexing, Slicing & Reshaping
3. NumPy Mathematical & Statistical Operations
4. Pandas Series & DataFrame
5. Reading & Inspecting Data
6. Selecting, Filtering & Sorting Data
7. Handling Missing Values
8. Merge, Concatenate, GroupBy & Pivot Table
9. Exporting Data
10. Mini Data Analysis Project

## Mini Project

Sales Data Analysis using NumPy and Pandas.

The project includes:

- Dataset loading
- Data inspection
- Missing-value analysis
- Filtering
- Sorting
- GroupBy analysis
- Pivot Table
- Statistical analysis
- Data export

## Key Learning Outcomes

- Working with NumPy arrays
- Performing numerical calculations
- Creating Pandas DataFrames
- Cleaning datasets
- Filtering and sorting records
- Combining datasets
- Performing GroupBy analysis
- Creating Pivot Tables
- Exporting processed datasets
